## Audit decisions

- Readme/checklist statements and source-level tests count as repository evidence, not proof of successful execution. No checks were run during this audit.
- A known CI failure takes precedence over documentation that describes a job as successful. CI status is considered unverified until a green default-branch run.
- An item needing both a code repair and an external action is listed in the implementation plan for the repair and here for the remaining owner action.
