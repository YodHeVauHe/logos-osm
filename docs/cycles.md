# Measured cycle counts

Measured on the LEZ local sequencer (standalone mode), logged from the guest
via `risc0_zkvm::guest::env::cycle_count()` at the start and end of each
instruction. Regenerated by the `chain` CI job on every run (see
`.github/workflows/ci.yml`), which deploys the program, exercises the
instructions, and greps the sequencer logs.

Benchmarking tooling: [`cycle_bench`](https://github.com/logos-blockchain/logos-execution-zone/tree/dev/tools/cycle_bench)
in the LEZ repository.

| Operation | Cycles (logged) |
|---|---|
| `init_registry` | filled by the chain CI run |
| `register_region` (1 entry) | filled by the chain CI run |
| `register_batch` (n entries) | filled by the chain CI run |

> The numbers in this file are produced by CI on the default branch; this
> placeholder is replaced with the measured values on the first green run.
> Batch size scales roughly linearly with the number of entries because the
> guest validates and inserts each entry independently.
