# FURPS self-assessment — LP-0018

Per the [solution template](https://github.com/logos-co/lambda-prize/blob/master/solutions/LP-0000.md).

## Functionality

| Spec criterion | Where |
|---|---|
| Region discovery (Geofabrik index, level in tree, restricted to predefined set) | `osm_sdk/src/regions.rs` (frozen set + `refresh_from_index`), CLI `osm discover [--refresh]`, module `discoverJson` |
| Host workflow (fetch → store → register via LEZ program) | `osm_sdk/src/host.rs` (`OsmSdk::host_region`), CLI `osm host`, module `hostRegionsJson` |
| Download workflow (CID from Logos Storage, Geofabrik direct fallback, no Geofabrik round-trip needed to trust) | `OsmSdk::download_region` — hosted ⇒ `storage.get(cid)`; else Geofabrik; report includes checksum evidence |
| Bulk host with opt-out; overlap warning outside the partition | `OsmSdk::host_regions` — one `register_batch` tx; `SdkError::Overlap` guard; CLI `--exclude`; app bulk panel |
| Local import (MD5 verification at import time → store → register by CID) | `OsmSdk::import_local` (checksum override for offline/e2e), CLI `osm import` |
| Update check per region entry (country and subregions tracked independently) | `OsmSdk::check_updates` — matched on region path; CLI `osm check-updates`; app update banner |
| On-chain registry: required fields, unique region key with parent/level, queryable by region/parent/CID, batch registration | `osm_registry_core` (fields), guest `register_region`/`register_batch`; queries are off-chain borsh reads (`registry::query_by_*`) |
| Testnet 0.4 end-to-end | chain CI job (localnet) + operator deploy steps in README (`make deploy` against the testnet 0.4 zone) |
| OSM registry SDK: full API for the app, limited subset for consumers, separate published module, minimal embedding example | `osm_sdk` (full), `osm-module` (consumer subset via FFI), `docs/sdk.md` worked example |

## Reliability

| Spec criterion | Where |
|---|---|
| Upload retries with exponential back-off, clear error after exhaustion | `storage.rs` + `geofabrik.rs` shared `backoff_delays`, `SdkError::RetriesExhausted` |
| Import-time checksum verification fails gracefully | `ChecksumMismatch { region, expected, actual }` — exit code 2 in CLI, red badge in app |
| Registry entries ordered by timestamp for version sorting | `registry::query_by_parent` sorts ascending by `timestamp` (pinned by test) |
| No mandatory centralized external services | Only sequencer/LEZ node, Logos Storage, Geofabrik (index, checksums, fallback) — all user-configurable (`--geofabrik-base` mirror flag included); analytics: none |
